# /brief

The one morning report. Read `python3 ../../team/bin/brief.py inputs`, the calendar and the board; write the brief JSON (direction, start here, your day, sections, one decision, todo) under 250 words; render with `brief.py render` and post it: always to `../../team/inbox/<date>/report.md`, and to Slack if wired. Give orders with orders.py: at most 3 per intern, each a job inside that intern's role, never a send.

Finish every run with one line in `memory/log.md` and, in a scheduled run, your contribution in `../../team/inbox/<date>/theo.md`.
