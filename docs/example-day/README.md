# An example day

A made-up Tuesday at a made-up business, so you can see what the files look like before your own interns write any.
Alex runs **Acme Studio**, a three-person brand and web studio. The goal this quarter: four new retainer clients.
Northwind is the deal everyone is working on. Every name, email and figure here is invented.
